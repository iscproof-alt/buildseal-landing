How this experience works

A deterministic rule evaluator checks the offer against its budget, the supplier document and human approval. All three must pass. It creates assessment bindings using the existing assessment module, seals the decision and compares it with the previous sealed record using the decision-drift service.

This bounded example does not run the full NYM, A9 or A10 orchestration. A changed input associated with a changed decision is an attribution record, not proof of causality. A valid seal does not mean a correct business decision.

The separate verifier shows integrity, signature, timestamp, content and trust scope. Signer trust and strict verification are not implied here.
