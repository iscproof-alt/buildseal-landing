Definition
Epistemic Memory

The complete, cryptographically sealed record of what an AI system knew, what it decided, why it decided it, and how that knowledge changed over time. Not a snapshot. Not a log. A living, append-only proof chain — where every claim is classified, every context selection is recorded, every revision is sealed, and every refusal is a first-class audit event. BuildSeal implements epistemic memory across 13 infrastructure layers, all anchored to the ISCProof open protocol.

Protocol01
ISCProof v5.1
Open verification standard

Ed25519 signatures, RFC 3161 timestamps, JCS canonicalization, Merkle roots. The cryptographic foundation every other layer is built on. Open spec — no vendor lock-in.

Memory02
VEDM
Verifiable Epistemic Decision Memory

Every claim classified at generation: CONFIRMED, INFERRED, RECORDED_POINTER, or UNKNOWN. Epistemic scope drift is impossible — the boundary is sealed into the proof payload.

Audit03
EST
Evidentiary State Transition

Why a decision changed over time — sealed. Historical truth vs current truth tracked in an append-only chain with authority, semantic diff, and confidence scores.

Memory04
EML
Epistemic Meta Layer

Which records were retrieved, which were excluded, and why — captured at generation. Context selection is a first-class audit object. No reconstruction after the fact.

Memory05
PSM
Portable Sealed Memory

Full session context sealed into a single restorable link. Provable continuity across devices and sessions. Restoration, not reconstruction.

Boundary06
GABA Boundaries
Cryptographic refusal records

What the AI refused — and why — is also sealed. Inhibition events are first-class audit objects, not silent omissions. The AI's limits are as provable as its decisions.

Protocol07
Seal Engine
The sealing runtime

JCS canonicalization → SHA-256 → Ed25519 → RFC 3161 TSA → Merkle root. Deterministic, reproducible, independently verifiable at any future point in time.

Identity08
Epistemic Continuity
Identity across sessions

Reasoning posture, tone, and epistemic state sealed across sessions. The AI is provably the same agent it was in session one — or the delta is a sealed record.

Audit09
Full Audit Seal
Input + context + policy, all hashed

input_hash, context_hash, entity_state_hash, policy_hash — all captured at generation. Nothing reconstructed. The moment of decision is the proof.

Audit10
Forensic Events
Scope upgrades & contradictions

SCOPE_UPGRADE, EPISTEMIC_REVISION, CONTRADICTION — when the AI changes its understanding, the change itself becomes a sealed forensic record.

Identity11
Cognitive State
Sealed runtime state

Coherence, trust level, threat index, signal strength — the AI's internal state at decision time is in the seal payload. Attested runtime state, not roleplay.

Protocol12
Challenge Endpoint
Evidence without inference

Returns pure database evidence packets — no model, no interpretation. The cryptographic proof speaks for itself. Regulators and auditors query directly.

Memory13
Relation Graph
Decision lineage

Decisions relate: supports, contradicts, derived_from, supersedes, delegates_to. The full epistemic graph of an AI system — sealed, queryable, verifiable at any depth.
